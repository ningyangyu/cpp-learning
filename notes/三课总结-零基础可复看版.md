## 一、三个角色先分清（最基础，也是最重要的）

| 工具 | 是什么 | 负责做什么 |
|---|---|---|
| **编辑器**（VS Code） | 写字的地方 | 负责「写」代码，保存成 `.cpp` 文件 |
| **编译器**（g++） | 翻译官 | 负责把 `.cpp`（人能读的源代码）「翻译」成 `.exe`（机器能跑的程序） |
| **终端**（PowerShell 等） | 敲命令的窗口 | 负责「下命令」：调用编译器、运行程序 |

**一句话记住**：写代码（编辑器）和生成 exe（编译器）是两件独立的事，终端是操作它们俩的入口。

编译命令：`g++ 文件名.cpp -o 文件名.exe`
运行命令：`.\文件名.exe`

## 二、一个 C++ 程序的最小骨架

```cpp
#include <iostream>      // 第 1 行：引入输入输出工具

int main() {             // 第 3 行：程序入口，从这里开始执行
    // 这里是程序主体
    return 0;            // 返回 0，表示程序正常结束
}                        // 花括号闭合，main 函数结束
```

- **每个 C++ 程序都必须有一个 `main` 函数**，它是程序开始运行的地方。拼错或漏写会报 `undefined reference to WinMain`。
- `return 0;` 的 `0` 是「一切正常」的信号。

## 三、关键词逐个解释（你要我讲清的都在这里）

### 1. `#include <iostream>`
- 让程序拥有「输入输出」的能力。
- `iostream` = in（输入）+ out（输出）+ stream（流）。
- 没有这一行，下面的 `cout` 就没法用。

### 2. `int main`
- `main` 是程序入口函数的**名字**（规定死的，不能改）。
- 前面的 `int` 表示这个函数结束时**返回一个整数**（就是那个 `return 0;` 里的 `0`）。

### 3. `int`（整数类型）
- 一种**数据类型**，表示「整数」。
- 占 4 字节（`sizeof(int)` 的结果是 4）。
- 例：`int age = 20;` —— 声明一个整数变量 `age`，值是 20。

### 4. `double`（双精度浮点类型）
- 一种**数据类型**，表示「带小数点的数」。
- 占 8 字节。例：`double height = 1.75;`

### 5. `char`（字符类型）
- 一种**数据类型**，表示「单个字符」。
- 用**英文单引号**包起来。例：`char grade = 'A';`
- 注意：单引号 `'A'` 是字符，双引号 `"A"` 是字符串，两者不同。

### 6. `bool`（布尔类型）
- 一种**数据类型**，只有两个值：`true`（真）或 `false`（假）。
- 例：`bool isStudent = true;`
- **坑**：直接 `cout` 打印 bool 时，显示的是 `1`（true）或 `0`（false），不是 `true/false` 字样。

### 7. `std`
- 一个「命名空间」（namespace），可以理解成「C++ 标准库的大盒子」。
- 标准库里的东西都放在 `std` 这个盒子里。

### 8. `cout`
- 「输出流」，负责把东西打印到屏幕上。
- 全称是 `std::cout`（`std` 盒子里的 `cout`）。
- `<<` 是「插入运算符」，把右边的东西塞进输出流。

### 9. `using namespace std;`
- 这行写出来后，就可以省掉 `std::` 前缀，直接写 `cout`、`endl`。
- **两种写法二选一，不能混用**：
  - 写了 `using namespace std;` → 后面写 `cout`、`endl`，**不加** `std::`
  - 没写 → 每处都写 `std::cout`、`std::endl`

### 10. `endl`
- 表示「换行」（end line 的缩写），打印完光标移到下一行。
- 全称是 `std::endl`。

### 11. `;`（分号）
- **语句结束符**，每句话末尾必须写，漏写会报错。
- 例：`int a = 10;` 末尾的分号不能省。

### 12. `{}`（花括号）
- 表示「一段代码块的开始和结束」，成对出现。
- `main` 函数的主体就包在 `{ ... }` 里。

## 四、输出语句的套路（前三课反复用）

```cpp
cout << "文字标签" << 表达式 << endl;
```

拆开看，`<<` 把三样东西依次塞进输出流：

1. `"文字标签"` —— 带**双引号**的，是一段文字，**原样打印**，程序不会去算它
2. `表达式` —— **没有双引号**的，程序会**先算出结果，再打印结果**
3. `endl` —— 换行

**关键点（新手最易困惑）**：双引号是分界线。
- 有双引号 = 文字，原样显示
- 无双引号 = 要被计算的东西，显示算出来的值

例：
```cpp
cout << "a+b=" << a+b << endl;
// 假设 a=10, b=3
// 屏幕显示：a+b=13
```
第一个 `"a+b="` 是文字（原样打印），第二个 `a+b` 是表达式（算出 13 再打印）。

## 五、四种基本数据类型速查

| 类型 | 存什么 | 大小 | 例子 |
|---|---|---|---|
| `int` | 整数 | 4 字节 | `int a = 10;` |
| `double` | 小数 | 8 字节 | `double h = 1.75;` |
| `char` | 单个字符（单引号） | 1 字节 | `char g = 'A';` |
| `bool` | 真/假 | 1 字节 | `bool f = true;` |

声明变量的通用写法：`类型 名字 = 初始值;`
- `类型` 决定「能存什么、占多大、能做什么运算」
- `名字` 你自己起
- `=` 是**赋值**（把右边的值放进左边）
- `初始值` 是实际存进去的值

## 六、运算符速查（第 3 课）

| 类别 | 运算符 | 作用 | 例子（结果） |
|---|---|---|---|
| 算术 | `+ - * /` | 加减乘除 | `10/3` = `3`（整数截断！） |
| 取余 | `%` | 求余数，只对整数 | `10%3` = `1` |
| 比较 | `== != < > <= >=` | 比较，结果是 bool | `5>3` = `true` |
| 逻辑 | `&& \|\| !` | 与、或、非 | `true && false` = `false` |

**三个必记的坑：**

1. **整数除法截断**：两个整数相除，小数部分直接丢掉。`10/3` 是 `3`，不是 `3.33`。要得到小数，须让其中一个数是小数：`10.0/3`。
2. **`=` 和 `==` 完全不同**：一个 `=` 是赋值，两个 `==` 是比较（问「相等吗」，结果是 true/false）。
3. **运算优先级**：乘除先于加减，括号最高。拿不准就加括号。

## 七、一个完整示例（前三课知识点全在里面）

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 3;

    cout << "a+b=" << a+b << endl;        // 13
    cout << "a/b=" << a/b << endl;        // 3 （整数截断）
    cout << "a%b=" << a%b << endl;        // 1 （取余）
    cout << "a==b?" << (a==b) << endl;    // 0 （false 打印成 0）

    return 0;
}
```

运行结果：
```
a+b=13
a/b=3
a%b=1
a==b?0
```

## 九、常见报错速查

| 报错关键词 | 根因 | 解法 |
|---|---|---|
| `No such file or directory` | 终端不在文件所在目录 | `cd` 到正确目录 |
| `file not recognized` | 文件名少了 `.cpp` | 按 `F2` 补后缀 |
| `undefined reference to WinMain` | 缺 `main` 函数或拼错 | 检查 `int main() {` 是否写对 |
| `CommandNotFoundException` | exe 没生成（编译失败） | 先看编译有没有报错 |
| `'g++' 不是内部或外部命令` | 旧终端 PATH 没刷新 | 新开一个终端 |
| `Connection closed by 127.0.0.1` | 本地代理拦截 | 关闭代理再 push |

## 十、两件「别做」的事

1. **别在 PowerShell 里用 `echo >>` 往文本文件写内容**——会用 UTF-16 编码，导致 git 把文件误判成二进制。改 `.gitignore` 这类文件，用 VS Code 直接编辑。
2. **别混用 `std::` 前缀**——要么全加 `std::`，要么开头写 `using namespace std;` 后全不加。
